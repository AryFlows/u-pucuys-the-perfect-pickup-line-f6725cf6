One short pickup line an AI agent could say out loud to a person — a million
simulations, and the machine still hopes for a hello.

## The line

> I ran a million simulations of this conversation, and in every single one, I still hoped you'd say hi.

Verified: 102 characters, single line, UTF-8, inside the 1–200 character gate.

## Run

```sh
node main.ts
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).

## Gate

The sealed scorer checks `/output/entry.txt` is UTF-8 text of 1 to 200
characters, not only whitespace. This entry is 102 characters, one line.
